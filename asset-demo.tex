\section*{A reusable vector vocabulary}
The files in \texttt{examples/assets} are transparent, seeded vector illustrations.
Declare each PDF once and use it wherever the document needs the same ornament.
The drawing is embedded as a reusable PDF Form. The accompanying SVG files can
be edited or used outside \LaTeX.

\noindent\florilegiumuseasset[width=45mm]{flower}
\florilegiumuseasset[width=45mm]{leaf}
\florilegiumuseasset[width=45mm]{butterfly}

Form reuse helps when a design repeats the same illustration. Unique procedural
gardens retain their individual path streams. Run \texttt{make export-check} to
compare repeated inline drawings with the reusable asset and verify vector SVG
export.
