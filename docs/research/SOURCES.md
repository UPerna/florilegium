## Metadata and permission findings

- R03 is Matthew Kaplan and Elaine Cohen, not Craig S. Kaplan. R10a has five authors including François X. Sillion; R10b has four authors and is a distinct INRIA report, with the June 2006 report carried in the March 2008 arXiv v2. They cannot silently substitute for each other.
- R12 first-page PDF and reference block confirm Aviv Segall, Jing Ren, Martin Schwarz and Olga Sorkine-Hornung, SIGGRAPH Conference Papers 2025, 15 pages, DOI 10.1145/3721238.3730649. The project header omits Schwarz and says ACM Transactions on Graphics; its BibTeX and code README include Schwarz. Use the paper metadata. The paper states CC BY 4.0; the reference code README states CC BY-NC 4.0. These are separate permissions. Independently authored equation-based Lua is the intended integration route; do not import the NC code into the MIT core. [Paper](https://segaviv.github.io/papers/gothic_microarchitecture/gothic.pdf), [pinned reference code](https://github.com/llorz/SIG25_goldschmiedrisse/tree/c48eae8ed972e127c2bd2a3adb430ad27aff7612).

Restricted PDF copies/text remain in private work storage, outside source/history, release packages and outputs. Use original text/images and separately licensed fonts. [Permission notice](https://www.cs.ubc.ca/labs/imager/tr/2011/Micrography/).
- R14 reference app is BSD-3-Clause at 4bb9d01999e4e84accc2a78d0fa279ef20b47263. Preserve its notice if reused. ## Scope and fidelity

The five durable contracts remain definition, instance, view, scene and build record, with validated Design Specification input. Mandatory family scope is 2D ornament plus genuine 3D Gothic curve networks and their projections/export. It does not include manufacturing-ready solids. Gothic tracery is a source-led 2D subset of R06, not a claimed manifold-mesh reproduction. Classical Islamic mandatory targets are Euclidean; hyperbolic/spherical source capabilities are explicit optional extensions. Penrose begins with P3 rhombi using published multigrid rules; P2 kite/dart representation is explicit optional scope. Hat, Tile(1,1) and genuine curved Spectres are different cases. Finite checks do not establish infinite aperiodicity.

COVERAGE.csv contains 45 mandatory targets and six explicit optional source extensions. Optional variants are not counted as mandatory completion evidence: curved-space Islamic motifs, freeform gadgets/toroidal packing, P2 representation, source 3D tracery meshes, Sky/Water variants and the separate 2026 morphogenesis study. Their tasks and owners remain visible. All 40 numbered stages are mandatory. No new family has been removed or replaced by an anonymous approximation. Existing floral output is identified as a verified adaptation, with its source-led rule semantics recorded separately.

Mandatory micrography scripts: Latin, Latin combining-character case and Greek; other scripts must fail with a useful unsupported-script diagnostic until independently verified. Use original text, a pinned redistribution-safe font and a justified shaping route at stage 24. Source-method layout and additional Unicode/backend semantics have separate ledger rows.

R13 audits control mechanisms: exemplar input, parameters, handling, filling, guide paths/fields and placement; assess global/local influence and edit timing against actual generator support. It is not a promise to implement every work in the survey. Fields/hatching, maze graph solutions and text reading order retain their semantics through later CLI/browser/export gates.

## Freshness observations

R14 v3 (July 2024) and R15 v2 (September 2024) are the journal-era revisions selected for implementation. The 2025–2026 [Encoding-Decoding Constellations exhibition](https://rebeccayelin.github.io/encoding-decoding-constellations/) documents later material/artwork explorations; it does not silently replace R05 v1 (2023). R17 by Zoltán Bereczki was published 16 April 2026 and studies recursive procedural morphology; it is an optional separate evaluation, not R12 reconstruction. R18 was inaccessible and supplies no verified algorithm or interface claims.
